Luyện tập Chương 4: tải 3 pha đối xứng nối sao (Y) và tam giác (Δ). Chọn dạng bài, nhập kết quả rồi bấm Kiểm tra; mỗi bài có hình mạch và lời giải từng bước. Tab Đề ngẫu nhiên sinh đề mới không giới hạn. Lý thuyết và ví dụ mẫu: Chương 4: Mạch điện xoay chiều 3 pha.

Cách nhập: số thập phân dùng dấu phẩy hoặc dấu chấm (8,78 hay 8.78). Được chấm đúng khi lệch không quá 1% so với đáp số, nên làm tròn Ip 2 chữ số rồi mới tính P, Q, S vẫn được tính là đúng.

Ký hiệu: chỉ số d = dây, p = pha. Nối Y: Ud = √3·Up, Id = Ip. Nối Δ: Ud = Up, Id = √3·Ip. Zp = √(Rp² + Xp²), cosφ = Rp/Zp.

Công suất: P = 3·Rp·Ip² (watt oát, W) ; Q = 3·Xp·Ip² (VAr) ; S = 3·Up·Ip = √(P² + Q²) (VA). Điện áp tính bằng volt vôn (V), dòng điện bằng ampere am-pe (A), trở kháng bằng ohm ôm (Ω).
